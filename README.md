# المنبت — سر الخير

متجر إلكتروني عربي (RTL) مبني بـ Angular 16 من تصميم Stitch وهوية المنبت.

## التشغيل

```bash
cd al-manbat
npm start
```

ثم افتح `http://localhost:4200`.

## البناء

```bash
npm run build
```

## ملاحظات الربط لاحقاً

الخدمات في `src/app/core/services` معلّمة بحدود محاكاة (MOCK BOUNDARY) لربط الكتالوج، الحساب، الدفع، والشحن دون تغيير الواجهة.
